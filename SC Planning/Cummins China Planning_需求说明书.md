## 1. 概述

### 1.1 背景与目标

为康明斯中国 Planning 业务提供统一的供需协同工作台，覆盖：

1. **业务协同**：需求数据上传、双周需求与 MAPE 报告、风险零部件、供需协同地图驾驶舱  
2. **数据维护**：Entity/机型、组织层级、组织地址、供需协同关系  
3. **系统管理**：菜单、用户、用户组

| 普通用户 | 业务协同（上传/报告/地图等）；上传受「可上传数据」权限控制 |

- 所属 Entity：`ACPL`（上传、更新风险时锁定为本 Entity）

### 1.3 产品信息

- 中文名：Cummins China Planning · 供需协同价值链  
- 英文副标题：Supply-Demand Value Chain / Planning Collaboration Platform  
- 品牌色：康明斯红 `#d6001c`  
- 时区：北京时间（UTC+8）  

### 1.4 技术形态（原型）

- 单文件 HTML + CSS + 原生 JS  
- ECharts 5（报告图表、中国地图）  
- SheetJS / xlsx（模板下载、导出、导入解析）

## 3. 业务协同需求

### 3.1 上传数据

**目标**：按条件查询各 Entity 的需求上传清单；有权限用户按 Meeting Date 上传本 Entity 数据。

#### 3.1.1 筛选

| 筛选项 | 规则 |
|--------|------|
| 需求年月 | 月份区间；提示最多 24 个月 |
| Meeting Date | 日期区间；跨度最多 24 个月 |
| 数据上传时间 | 日期区间；跨度最多 24 个月 |

操作：查询、重置。

#### 3.1.2 列表

- 固定列：Entity、Engine、Meeting Date  
- 动态列：按年分组的月份列（Jan–Dec）+ **Total**  
- 演示数据跨度示例：2025-08 ～ 2026-12  

操作：下载模板、上传数据、导出列表。

#### 3.1.3 上传弹窗

| 字段 | 规则 |
|------|------|
| Meeting Date | 必填；默认当天（北京时间） |
| 更新 Entity | 只读，固定为当前用户所属 Entity |
| 文件 | `.xlsx` / `.xls` |

**权限规则**

- 无「可上传数据」权限：不展示「上传数据」按钮  
- 有权限：仅可上传**自己所属 Entity** 的数据；文件含其他 Entity 应失败  

**失败场景（演示）**：Meeting Date 为空、非本 Entity、模板过旧、网络异常等。

---

### 3.2 供需协同报告

**目标**：按组织与机型维度查看 Bi-weekly Demand 与 Engine Plant M-2 MAPE。

#### 3.2.1 筛选（多选）

- 需求年月（年→月树；当前年默认展开；最多选 24 个月）  
- Consol、JV、BU、Entity  
- Application、Category、Engine Platform  
- 查询 / 重置  

> 原型中查询/重置多为演示提示，正式版需驱动图表与表格重算。

#### 3.2.2 Bi-weekly Demand

- **图**：按 Entity 堆叠柱；柱内展示分段值；柱顶展示月合计；当前自然月轴标「本月」  
- **表**：Entity × 月份；Entity 列固定；最多展示 **15** 个 Entity  
- **差异规则**（相对上一版本，仅预测月）：  
  - \|Δ\| ≥ 30% 且 ≤ 50%：黄色角标  
  - \|Δ\| > 50%：红色角标  
  - \|Δ\| ≥ 30%：显示 ▲（高于上一版）/ ▼（低于上一版）  
- 图例说明：黄/红区间与涨跌箭头含义  

#### 3.2.3 Engine Plant M-2 MAPE By Entity

- **图**：以 0% 为基准的正负柱  
- **表**：Entity × 月份  
- **月份规则**：仅展示**当前北京月之前**的月份（不含当月及以后）；正值偏红、负值偏蓝，以 % 展示  

---

### 3.3 风险零部件

**目标**：维护并查询随上传同步的最新风险零件清单；与地图节点悬浮联动。

#### 3.3.1 列表与筛选

**列表列**

| 列名 | 说明 |
|------|------|
| 序号 | — |
| Meeting Date | 原「上传版本」业务字段，列表展示名称为 Meeting Date |
| Entity | — |
| 零件号 | — |
| 零部件名称 | — |
| 风险描述 | — |
| 影响 | — |

**筛选项**：上传版本、Entity、零件号、零部件名称、风险描述、影响（与列表列对应；正式版建议筛选项标签与 Meeting Date 对齐）。

分页：共 N 条；每页 10 / 20 / 50。

操作：下载模板、导出风险信息、导入、更新风险。

#### 3.3.2 更新风险弹窗

| 步骤 | 行为 |
|------|------|
| 是否有风险 = **否** | 仅保留 Meeting Date；保存后清除当前用户 Entity 下全部风险记录 |
| 是否有风险 = **是** | 可编辑多行（+/-）；Entity 只读锁定为当前用户 Entity |
| 行字段 | Meeting Date、Entity、零件号、零部件名称、风险描述、影响 |
| 约束 | 「是」时至少 1 行；不可删至 0 行（需改选「否」） |
| 保存 | 用新行**整体替换**该 Entity 既有风险数据 |

---

### 3.4 供需协同地图（驾驶舱）

**目标**：以中国地图可视化 Entity 节点与供需连线，并展示风险预警。

#### 3.4.1 布局与 KPI

- 标题：供需协同价值链 · 驾驶舱（LIVE）  
- KPI：协同 Entity 节点、供需协同连线、风险零件预警、覆盖机型、组织总数（及省级枢纽等扩展指标）  

#### 3.4.2 地图

- 中国 Geo 底图；滚轮缩放、拖拽平移  
- **Entity 节点**（红）与 **核心协同节点**（青，原型：`CCS-WH`、`XCEC`）  
- **飞线**：启用状态的供需协同关系（供方/需方均有坐标时绘制）  

#### 3.4.3 交互

| 对象 | 悬浮内容 |
|------|----------|
| 节点 | Entity 名；未来 6 个月最新版预测（Engine × 月）；该 Entity 最新风险零件（或「暂无」） |
| 连线 | 供方 → 需方、关系 ID、产品、信息流、实物流 |

#### 3.4.4 风险预警侧栏

- 标题：风险零件预警 · 最新版  
- 可折叠；条目 > 2 时自动滚动展示

## 4. 数据维护需求

### 4.1 Entity 和机型维护

**目标**：按 Entity 维护机型维度：Application、Category、Engine Platform、备注。

#### 4.1.1 展示

- 汇总：Entity 总数、机型总数  
- 按 Entity 分块表格：序号 | Application | Category | Engine Platform | 备注 | 操作  

#### 4.1.2 编辑模式

- 进入编辑：基于草稿修改；保存提交；取消丢弃  
- 可搜索下拉选择 Application / Category / Engine Platform  
- 块级：+ 新增机型、删除 Entity  
- 行级：删除（仅编辑态）、**失效 / 启用**（编辑内外均可）  
- 顶栏：+ 新增 Entity、保存、取消  

#### 4.1.3 失效规则

- 失效行置灰，并标记「已失效」  
- 失效数据默认沉到**当前 Entity 分组**底部  

可选值（原型）：

- Application：On-highway / Off-highway / Industrial / Powergen  
- Category：Light Duty / Medium Duty / Heavy Duty / Others  
- Engine Platform：4.5FE / NS6 / Frodo / Fencer / 15N / 15NFE / Off-highway / NO-NS6 等  

支持：下载模板、导入。

---

### 4.2 组织层级关系

**目标**：维护三级组织树：一级（如 Consol/JV）→ 二级 BU → 三级 Entity。

#### 4.2.1 能力

- 统计：一级 / 二级 BU / 三级 Entity 数量  
- 折叠末级 / 展开末级  
- + 新增一级节点  
- 节点操作：+ 新增下级（Entity 级不可再增）、编辑、**失效/启用**、删除  
- BU 节点展示下属 Entity 数量  

#### 4.2.2 规则

- 存在下级时不允许删除  
- 失效节点置灰并标「已失效」；同级内失效项沉底  
- 下载模板、导入  

---

### 4.3 组织地址坐标

**目标**：维护组织简称、全称、地址与经纬度（含东西经、南北纬）。

#### 4.3.1 列表

序号 | 简称 | 全称 | 具体地址 | 经度 | 纬度 | 操作（修改 / 失效|启用 / 删除）

分页展示。

#### 4.3.2 编辑弹窗

- 简称（必填）、全称、具体地址  
- 经度：0–180 + 东经 E / 西经 W  
- 纬度：0–90 + 北纬 N / 南纬 S  

#### 4.3.3 失效规则

- 失效行置灰并标「已失效」；沉到列表底部  

支持：下载模板、导入、新增。

---

### 4.4 供需协同关系

**目标**：人工维护供方/需方协同主数据，供地图连线与悬浮明细使用。

#### 4.4.1 列表字段

序号 | 关系ID | 供方 Entity | 需方 Entity | 产品 | 信息流 | 实物流 | 状态 | 操作（编辑/删除）

#### 4.4.2 编辑

- 关系 ID 必填  
- 状态：启用 / 停用  
- **停用**关系不参与地图连线绘制  

支持：下载模板、导入（界面文案可为「上传」）、新增关系。

## 5. 系统管理需求

### 5.1 菜单管理

- 树形列表：菜单名称、编码、路由、图标、排序、状态  
- 最多 3 级；有下级时不可删除  
- 操作：新增下级（非末级）、编辑、删除；支持新增根菜单  

### 5.2 用户管理

**列表**：WWID、用户名、用户组、Entity、邮箱、最近登录、可上传数据（开关）、状态、操作  

**筛选**：关键字（WWID/用户名）、Entity、用户组  

**操作**：编辑、重置密码（可随机生成）、禁用/启用；下载模板、导入、新增用户  

**可上传数据**：控制上传页是否展示上传入口。

### 5.3 用户组管理

**列表**：用户组名称、成员数、关联菜单权限、状态  

**编辑**：名称、状态、菜单勾选  

**成员管理**：未加入用户 ↔ 组内用户；移出后默认回落「普通用户」  

原型默认组：系统管理员、组织管理员、普通用户。

## 10. 原型与正式版差异 / 待澄清项

1. **命名统一**：风险列表列名为 Meeting Date，筛选/模板仍可能写「上传版本」——建议产品统一术语。  
2. **报告筛选**：原型查询多为演示，正式版需真实过滤图表与表格。  
3. **导入落库**：原型仅解析计数；正式版需写入并做校验、权限、审计。  
4. **级联筛选**：组织 Consol/JV/BU/Entity 与机型 Application/Category/Platform 建议正式级联。  
5. **菜单/用户「新增」**：部分入口为占位提示，需补全表单与校验。  
6. **地图预测数据**：节点悬浮的 6 个月预测在原型中为演示随机值，正式版应对接最新上传版本。
